 ---------EVENT BUBBLING-----------------
 Event bubbling is a concept 
 When an event is triggered on an element:

The event starts at the target element.
It then propagates upward through the parent elements until it reaches the <html> element.
If an event listener is attached to any of these parent elements, it can respond to the event.
